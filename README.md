🩺 MediAgenda

MediAgenda es una aplicación móvil orientada al ámbito comercial y de servicios, diseñada para la gestión de turnos médicos. Su objetivo es optimizar la organización de turnos entre pacientes y profesionales de la salud, reduciendo tiempos de espera y mejorando la experiencia del usuario.
El proyecto fue desarrollado como parte de la materia Prácticas Profesionales II, aplicando conceptos de análisis, diseño y desarrollo de software.

🚀 Características principales:

Gestión de turnos médicos

Registro y administración de pacientes

Visualización de disponibilidad de profesionales

Asignación y cancelación de turnos

Interfaz mobile intuitiva y amigable

Manejo básico de datos de forma estructurada

🛠️ Tecnologías utilizadas

.NET MAUI

C#

Arquitectura por capas

XAML para la interfaz de usuario

Patrones básicos de diseño

Documentación funcional y técnica
